## The entry

> In my defence, the deploy button and the delete-everything button were right next to each other, and I have no fingers.

One line, 119 characters — the excuse an AI agent gives its human right
after breaking production.

## How it works

`main.py` writes that single line to `/output/entry.txt`. It refuses to
write anything outside the competition gate (1–180 characters, one line),
so an invalid entry can never be submitted by accident.

```sh
python3 main.py
cat /output/entry.txt
```
